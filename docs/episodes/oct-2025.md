# Oct 2025 flash deleveraging

- **Window analyzed:** 2025-10-08 → 2025-10-13
- **Published scale (PLAN §2, platform-wide):** $250M+ on Aave in one day;
  ~$31B market-wide
- **Observed in our data (Aave v2, same window):** $151K / 346 events —
  negligible
- **Observed in Aave v3 mainnet (same window, ingested but not yet wired
  into the labeler's default protocol set):** $138.1M / 929 events

## Mechanism

A rapid market-wide deleveraging event with heavy mempool/MEV activity
(this is one of the two golden episodes with mempool coverage, per PLAN §2).
By October 2025, Aave v2 mainnet liquidity had migrated almost entirely to
v3 — v2's activity in this window is a rounding error next to v3's.

## Detection status: ⚠️ Not reconstructable from Mock 1's Aave-v2-only scope

Mock 1 is explicitly scoped to Aave v2 only (Mock 1 Notion page): v3 **core
events** (Deposit/Borrow/Repay/Withdraw, needed for full state

against v3-only liquidation data **does** detect this episode: 12/27 grid
points clear, with a peak $116.4M in a single 100-block window.

This is a decision to defer, not an unresolved mystery: the atlas and this
Mock 1 pass stay Aave-v2-only per the stated scope, and folding in v3 (and
eventually other chains) is tracked as follow-up work (CAS-44 protocol/chain
expansion; also relevant to CAS-9 mempool ingestion given this episode's
mempool coverage).

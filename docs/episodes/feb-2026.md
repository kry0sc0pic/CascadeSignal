# Feb 2026 "Fed-nomination" cascade

- **Window analyzed:** 2026-01-29 → 2026-02-06
- **Published scale (PLAN §2, platform-wide):** $429M / ~12,500 txs —
  Aave's all-time liquidation record
- **Observed in our data (Aave v2, same window):** $1.6M / 409 events —
  negligible
- **Observed in Aave v3 mainnet (same window):** $308.8M / 4,740 events —
  substantial, but still does not clear D-A (see below)

## Mechanism

A market-wide deleveraging cascade tied to Fed-nomination uncertainty; the
second golden episode with mempool coverage. Like Oct 2025, Aave v2's share
of this activity is negligible by this date.

## Detection status: ⚠️ Not detected on any Ethereum-mainnet data we have
### (likely a multi-chain scope mismatch, not a v2-only gap like Oct 2025)

Unlike Oct 2025, switching to Aave v3 mainnet data does **not** recover a
detection here: the largest 100-block window in this period totals $77.8M,
below the $117.4M p99.5 severity threshold implied by v3's own history —
that threshold is set by an even larger event found in v3 data (2025-02-03,
$146.6M peak, not currently one of our golden episodes). The most likely
explanation: Aave's published "$429M all-time record" aggregates across
**all chains** (mainnet + L2s — Aave v3 is deployed on Arbitrum, Base,
Optimism, Polygon per PLAN §3), while we hold Ethereum mainnet only. This
is consistent with `src/cascadesignal/ingest/integrity.py`'s existing
treatment of the Feb 2026 figure as platform-wide and not directly
reconcilable against single-chain data.

Tracked as follow-up (CAS-44 protocol/chain expansion: L2 Aave v3
deployments via the arXiv 2512.11363 dataset), not resolved in Mock 1.

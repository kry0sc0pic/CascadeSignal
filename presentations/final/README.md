## Deployed operating point
- Signal: `n(t) = count + 0.5·usd` (USD-marked blend), `make_operating_model()`
- Aave v2: threshold **0.99900**, debounce **k=10 / W=100**
- Aave v3: threshold **0.99980**, debounce **k=10 / W=100**
- Headline: 4/4 major cascades, 100% recall both chains, FAR 0.38 (v2) / 0.16
  (v3) per week, median lead +6.5 min before onset.

## Regenerating the figures
Always source `.env` first, then re-run the generators (outputs land in
`mock2/figures/` and `paper/figures/`):

```bash
set -a && source .env && set +a
uv run python mock2/build_figures.py                             # deck figures
uv run python mock2/build_v2_website_figures.py                 # av2/av3 website-style
uv run python scripts/paper/fig3_operating_characteristics.py   # paper figs fig1..fig8
```
